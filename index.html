じこしょうかい

武蔵野大学でデータサイエンスを学んでいます。ゼミでは、データサイエンスを経営や意思決定にどう使うかを扱っています。

授業の課題で終わらせず、実際に動くアプリまで作るのが好きです。中小企業向けの経営指標診断ツールは一人で作り、Open DS AI Forum 2026で発表しました。

05

東京の観光スポット検索マップ

時空間データベースの授業課題

東京の観光スポットを地図の上で探せます。データはPostgreSQLに入れ、大学のサーバーに公開しました。

PHP ・ PostgreSQL ・ Leaflet.js

できること

  • データ分析Python（scikit-learn、mlxtend）で、回帰、クラスタリング、決定木、相関ルールを扱ってきました。
  • WebアプリNode.js、PHP、HTML / CSS / JavaScript で、画面からデータ処理まで一通り作れます。
  • データベースPostgreSQL と SQLite で、アプリのデータを設計して保存しています。
  • 見せ方Chart.js や Leaflet.js で図と地図を作り、報告書（ReportLab）と発表資料にまとめます。

いま考えていること

経営分野で研究をしたいと考えています。ゼミで作った経営指標のアプリを土台に、先生に相談しながらテーマを練っています。

診断の判定基準や比べる単位（業種の分け方、企業の規模）を変えると、結果はどれくらい変わるのか。

まずはオープンデータで小さく試して、実社会のデータで確かめるところまで進めたいです。
